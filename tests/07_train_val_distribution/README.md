# 实验07：训练集与验证集分布诊断

沿用当前ROI64的721名患者、既定五折及原始UNI＋ABMIL＋Cox的最佳checkpoint预测。
只读取现有输入和预测，不修改划分、标签、主流程或生存模型。

## 已确认的设计和实施计划

1. 分块读取每名患者全部UNI patch，计算1024维平均特征、patch数量、patch范数均值和标准差；缓存汇总及输入文件指纹。验证每折训练、验证预测的病例和标签与CSV完全一致。
2. 使用简单来源分类器判断当前折训练/验证归属。内部五折仅按event分层，与来源标签无关；每个内部训练部分单独拟合StandardScaler、32维PCA及L2正则LogisticRegression。报告内部留出AUC均值，并在event层内置换来源标签999次，保持原始划分规则和类别计数；五个来源检验使用Holm校正。所有模型设置事先固定，不根据DFS结果调参。
3. 在每个生存训练折单独拟合标准化＋白化PCA，以最近5个训练患者的平均距离表示验证患者偏离程度。将其及内部留出来源概率，与该患者在所有可比较对中的排序错误比例关联；输出描述性Spearman相关、远/近组错误率，并按event/观察时间分层核对。来源概率高代表更像验证来源，不是DFS风险或复发概率。
4. 逐折输出Train/Val C-index、患者对分解、按相同患者对组成加权的描述性差值，以及分布与错误关联。完成数值测试、合成数据的偏移检出检查，再运行真实数据并审查结果。

## 解释边界

- 来源判别AUC的置换区间是零假设参考区间，不是AUC置信区间。内部五折AUC标准差也不是置信区间。
- 均值池化＋32维PCA只是输入分布的简化探测，未检出差异不等于完全同分布；检出差异不等于它导致DFS泛化下降。
- 患者对共享患者。患者错误相关及远近组差值只做描述，不把数千患者对当作独立样本计算显著性。
- 时间/事件分层仅用于诊断，不用于构造病理特征、预测DFS或调整正式指标。
- 已有验证结果参与过选模。这里不产生独立测试性能，也不证明病理信息上限。
- 既往来源批次表仅作可选元数据，使用前严格核对患者及标签；特征统计全部重新读取计算。

## 运行

在项目根目录、UNI环境中：

```bash
python -u tests/07_train_val_distribution/analyze.py
```

输出位于本目录的`results/`，特征缓存位于`cache/`。脚本默认仅使用CPU。

后台运行和查看日志：

```bash
bash tests/07_train_val_distribution/run.sh
tail -f tests/07_train_val_distribution/analysis.log
```

数值与端到端测试：

```bash
python tests/07_train_val_distribution/test_analysis.py
```

## 2026-10-29本次实际结果

- 读取721名患者全部2,222,768个patch，无零向量或非有限特征；缓存为721×1024患者平均特征。十份预测病例及float32导出精度下的标签全部对应。
- 五折来源判别AUC依次0.4624、0.5369、0.4391、0.4734、0.5295；每折999次event内置换，Holm校正P依次1.000、0.755、1.000、1.000、0.812。在这个预先固定的简化特征探测中，没有检测到明显的整体输入分布差异。
- 训练/验证平均patch范数均约39.31，事件比例约34.7%～35.2%。Fold 4验证事件时间中位数36.1个月，对应训练21.0个月，是可观察到的随访组成差异。
- 验证患者距训练患者越远，错误率略高：五折描述性Spearman为0.194、0.217、0.128、0.253、0.224。按event和观察时间组做描述性秩残差调整后为0.130、0.151、0.106、0.151、0.171。关联较弱，也出现在表现较好的折。
- 来源概率与错误率没有一致的正向关联（五折rho为0.027、−0.146、−0.130、−0.071、−0.011）。不能据此支持“越像验证来源越容易出错”。
- Fold 0统一患者对组成后Gap仍0.1680；Fold 4由0.1704降至0.1457。当前检查没有充分解释这两折的大幅泛化差距。
- patch平均范数与错误率的描述性相关为负（约−0.19～−0.46），因此当前数据也不支持把“特征范数越大，预测就越差”当成简单解释；这不排除输入尺度对训练优化的影响。

这些结果不证明完全同分布、不证明模型结构无问题，也不证明病理DFS信息上限。患者均值会掩盖组织内异质性，固定PCA/线性分类器也存在检测能力限制。

## 主要输出

- `results/report.md`：逐折汇总及解释边界。
- `results/diagnostic_overview.png`、`.pdf`：现有Train/Val排序、来源置换检验、错误关联三面板图。
- `results/patient_summaries.csv`：所有患者输入统计、路径、标签及原始划分。
- `results/cohort_distributions.csv`、`source_batch_summary.csv`：每折训练/验证的随访、特征统计及已有来源批次分布。
- `results/fold_summary.csv`：原始/组成标准化CI、来源AUC和置换P、主要相关。
- `results/patient_errors.csv`、`pair_breakdown.csv`、`error_associations.csv`：病例错误、八类患者对、原始及时间/event调整后的描述性关联。没有可比较对的患者错误率为空，不删除病例。
- `results/origin_permutations.csv`：5×999次零假设来源AUC。
- `results/manifest.json`：输入文件哈希、运行参数、特征文件指纹。
