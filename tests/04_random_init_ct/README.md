# 04：单模态CT随机初始化

不加载MedicalNet或其他预训练权重，使用当前ResNetCox自身的初始化规则（卷积Kaiming初始化、残差末端BN权重为0等），骨干与风险头全部参与优化。

沿用主流程的3D ResNet18、全局平均池化和512→256→1风险头；Cox损失、尾部并入前一批、早停、最佳验证C-index选模、最终生存分析均复用主流程。不修改主流程文件。

默认配置：ROI96、Dropout 0.25、最多100 epochs、batch size 64、全模型统一LR=1e-4、weight decay=5e-4、patience=10。Adam只有一个参数组，骨干与风险头不区分学习率。训练seed默认123，启动及每折开始各设置一次。直接读取原CSV的五折划分，不重新划分，不读取病理特征。100轮结果使用新的epochs100目录标签，不覆盖此前30轮结果。

此前带`_blr`标签的结果属于旧版分组学习率实验；修正后的结果目录不含`_blr`，保留旧结果，不覆盖。

**与预训练主流程的区别**：除了初始化与统一学习率，本实验默认在训练阶段更新BN统计量，验证和最终评估使用eval模式；主流程固定BN运行均值/方差。随机初始化没有预训练BN统计量，因此默认不固定初始均值0、方差1。可直接运行train.py并加`--freeze_bn_stats`固定BN统计量，两种设置有不同的结果目录标签，但这不会恢复主流程的分组学习率。

运行（脚本内部已使用nohup后台运行并保存日志）：

```bash
bash tests/04_random_init_ct/train.sh
```

日志、权重、结果分别在本目录的logs/、checkpoints/、results/下。结果包含run_config.yaml、各折预测与KM曲线、合并的metrics.csv及五折均值±标准差。`--eval_only`读取同配置的best_model.pth重新评估。

这是统一学习率下的初始实验，不能据此判断随机初始化在充分调优后的性能上限。改变ROI时需与相同ROI的预训练实验比较。
