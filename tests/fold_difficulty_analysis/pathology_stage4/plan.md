按用户完整设计，仅分析已有实验10，不重训、不修改模型、不启动Stage5。
主要对象为full_repeat0五折Best与固定180步Last；另整理50次已有学习曲线训练。

- [x] 验证既定721例/251事件、原五折、冻结训练子集及源哈希。
  核对50组×20评估点、全部Best/Last Train/Val预测与病例/标签，
  复算C-index及float32事件平均Cox，核对Best为首个最大Val点、Last为180步。
- [x] 先写患者对回归测试：不同事件时间、同时间event/censor、同时间event/event、
  风险ties(1e-8)与半分修正、无可比较患者、输入顺序不一致的严格对齐。
- [x] pairs.py：沿用实验07方向，事件为较早者；风险ties给0.5。
  分开全分纠正/破坏与半分变化，精确复现官方sksurv C-index及其差值。
  时间按[0,12]、(12,24]、(24,36]、>36；同时间event/censor另列，不漏掉。

- [x] 整理50组学习曲线：先在每折平均重复抽样，再跨五折报告mean±样本SD。
  同时报告固定180步患者曝光数、曝光/训练人数、Best/Last差距、
  抽样重复差异和各固定更新点，不把15次抽样当15个独立Fold。
- [x] 输出report.md、可复算CSV及英文粗线大字体PNG/PDF；独立审查和最终数值核验。
  8项测试通过；审查独立随机500例ties对照官方sksurv通过；
  50组/1000个更新评估点/200份预测复算完成，输入哈希保持不变。

## 解释边界

Best由Outer Val选出，Best→Last差值带选模乐观偏差；患者对共享患者，
不做独立pair显著性检验。时间组中的占比必须结合分母/每对错误率看，
不能将36月后病例多直接解释为晚期风险更难。删失不等于永不复发。
Top患者是同数据上事后排序，覆盖率是描述，不是独立验证或标签错误证据。
学习曲线训练人数变化也改变事件数、每位患者曝光次数；只说明当前固定预算流程。
不能从风险/损失反推出模型学了哪种组织生物学；临床终点仍需数据提供方核对。
