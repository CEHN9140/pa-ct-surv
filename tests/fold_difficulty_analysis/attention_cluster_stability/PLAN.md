# UNI cluster / Best-to-Late attribution / Train-Val stability

Approved user scope: one no-training diagnostic, independently fit clusters in Outer Train, assign Val; no doctor or automatic tissue labels; no selecting/suppressing patches using these Val findings. Main flow and previous diagnostic artifacts remain read-only.

1. Predefine20fold-local MiniBatchKMeans classes on Raw UNI1024, no L2/PCA/Zscore. Per Train patient sample up to128 fixed feature rows; fit weights equalize patient total weight. seed123, batch2048, max_iter100, n_init3, max_no_improvement20. No labels/time guide dictionary fitting or K.
2. Five Train-only dictionaries, all3605 fold-patient bags assigned without updating centroids; exact H5 feature/coordinate and prior-best-IG source checks. Store all patch assignments privately. Aggregate counts, best/late attention mass and signed/absolute IG by class; check count/mass/IG completeness.
3. Per cluster, aggregate both endpoints' harm/repair support and opposition on changed comparable pairs. Normalize margins by that fold's full Train best-attention risk SD and split comparable-pair count; raw masses are not comparable across Train/Val. Net changed-margin contribution is not a C-index allocation or an independent causal effect.
4. Report Train/Val prevalence, attention allocation/enrichment, IG and normalized context margins. Val conditional bootstrap recomputes comparable pairs/credit transitions under fixed models and dictionary; within-fold20class simultaneous approximate bands, no claim to cover prior exploration/best selection. No Train significance from repeated patients across folds.
5. Do not equate class IDs across folds. Provide only descriptive Hungarian centroid correspondences (Raw Euclidean), mutual-nearest flags and distance/radius diagnostics; no pooled cluster predictions or confirmatory cross-fold biological labels.
6. Native technical QC:8fixed random patches per patient sampled independently of labels, IG and clusters, read once from SVS, assign to every fold dictionary. These sparse conditional summaries do not diagnose blur/tissue. Original thumbnails give all-patch coarse white-fraction proxy. All721OOF WSI color maps andup to4distinct-patient Train prototype patches per fold-class, explicit coverage; private images, no tissue names.
7. Tests: Train-only fit guard, deterministic sampling and patient weights, class completeness, endpoint-based normalized margin identity and bootstrap signs. Real cohort smoke before frozen-source background launcher. Independently recompute report from private patient-class rows, source risks, dictionaries/fit roles and assignments. No retraining or automatic push.

Files: cluster_tools.py mathematical/fit helpers; analyze.py dictionaries/assignments/aggregates; visualize_qc.py raw QC and WSI maps/prototypes; report.py independent checks/bootstrap/summary; pipeline.py/run.sh lifecycle. Patient rows, centers, maps, arrays and review images remain under private/. Public results are aggregate only. Same UNI clusters can reflect stain/scanner/tissue-density differences; cluster labels are not histology.
