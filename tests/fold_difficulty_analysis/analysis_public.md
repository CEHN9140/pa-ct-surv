# ROI64病理五折差异诊断（2026-10-25）

本分析使用已有模型与验证预测，不训练模型、不改变划分、不修改源数据、不剔除病例。
队列为data/trident/features_uni_v1/all_label_roi64.csv：721名患者，251例event=1。
沿用原有event编码；与HE预后.xlsx一致，不代表已独立确认临床终点定义。

## 主要发现

1. 全部721名患者的病理ID、CT ID、时间、事件均与原始HE预后.xlsx一致；患者ID和特征路径无重复。
2. 五折事件数为51/50/50/50/50；没有发现Fold 0/4因事件数量更少而失衡。
3. Fold 4的事件明显偏晚：事件时间中位数36.1个月，12个月内事件仅5例；其余折为16～19例。
   这是这次固定划分的具体组成差异。事件时间的五折Kruskal-Wallis探索性P=0.0243，未作多重比较校正。
4. 事件时间组成并非完整解释：将0–12、12–24、24–36、36个月后的事件锚点患者对比例统一为全队列合并比例，
   L2 ABMIL的Fold 4描述性标准化C-index仅由0.7025变为0.7121，Fold 2仍为0.7844。
   此分解仅描述患者对组成，不是因果分析，也不替代正式指标。
5. Fold 0/4主要困难是事件患者与随后仍未观察到事件的删失患者之间的区分，尤其是较晚事件。
   它们的事件患者彼此排序并非统一更差。病例级错误在原始ABMIL与L2 ABMIL间的Spearman相关为
   Fold 0=0.8711、Fold 4=0.9317；KEEP、MeanPool等也有重复错误。
6. CT对同一ROI64患者的验证C-index为0.7157/0.7091/0.7888/0.7082/0.6443。
   Fold 0在CT并非最弱；Fold 4在病理和CT均偏弱。不能将两折解释为完全相同的病理训练问题。
7. patch数量中位数为3160/3065/2878/3004.5/3107.5；五折分布Kruskal-Wallis探索性P=0.2648。
   所有721份UNI特征及坐标H5头部数量匹配，维度均1024。
   每张最多64个等距patch的特征抽样中未见非有限值或零向量；各折平均范数约39.31～39.35。
   这不是完整WSI伪影检查，也不是全部patch数值审计，不能排除组织选择或图像质量问题。
8. 原始匹配表的第一批/第二批来源比例没有明显折间差异（探索性P=0.6683），
   因而未发现简单的来源批次比例失衡。来源批次本身事件比例不同，不宜当成无关信息或临床分期。

## 不确定性与未解决问题

- 使用固定验证预测进行2000次患者级bootstrap。L2 ABMIL：Fold 0 C-index约0.6893，
  95%百分位区间[0.6209,0.7574]；Fold 2约0.7855，[0.7189,0.8437]；Fold 4约0.7025，
  [0.6144,0.7837]。此区间以已训练且已选模的预测为条件，不含重新训练与选模不确定性。
  种子间均值接近，不代表患者抽样的不确定性很小；不能用区间重叠直接完成显著性检验。
- 不同折既改变验证病例，也改变训练队列，现有交叉验证不能完全分离验证病例难度与训练队列影响。
- 多种模型使用相关特征/相同标签，并不是独立重复的临床证据。
- HE预后.xlsx只有病理号、ID、DFS.months、DFS.status；其余当前原始表亦未提供分期、组织学类型、
  肿瘤大小和治疗情况，无法据此断定具体临床原因。
- 当前已定位的是反复出错的患者关系和相关随访组成，尚未证实病理信息上限、标签错误或唯一生物学原因。
